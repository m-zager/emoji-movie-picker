# 🎬 Emoji Movie Picker

Can't decide what to watch? Tap a few vibe emojis (😂 😱 🚀 🦖 …) and get a ranked list of matching movies, or hit **🎲 Surprise me** for a single random pick.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Project layout

- `app/page.tsx`: page shell
- `app/emoji-movie-picker.tsx`: interactive picker (client component)
- `app/movies.ts`: vibe emojis, movie list, and the ranking function. Add movies here.
